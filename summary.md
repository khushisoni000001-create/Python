## Project Summary

The Digital Notes Management System is a simple Python-based project developed to make storing and managing notes easier.

It allows users to:
- Add new notes.
- View all saved notes.
- Search notes using keywords.
- Edit existing notes.
- Delete notes when they are no longer needed.

The project uses Python functions to perform different operations and a text file (`notes.txt`) to store notes permanently. Each note is given a unique ID to make it easy to identify and manage.

The program has a simple menu-driven interface that allows users to select the operation they want to perform.

## Difficulties Faced

While developing this project, I faced some difficulties:

- Understanding file handling in Python.
- Generating unique IDs for notes.
- Searching notes using keywords.
- Editing and deleting notes using their IDs.
- Handling empty inputs and testing different operations.

I solved these problems by practising Python concepts and testing the program.
