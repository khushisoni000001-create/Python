# Digital Notes Management System

## About the Project

The Digital Notes Management System is a simple Python-based project that helps users manage their notes. Through this program, users can add new notes, view saved notes, search for a particular note, edit its content, and delete notes whenever required.

I developed this project using Python 3. The main idea behind it is to make note management simple and to understand how data can be stored and accessed using file handling.

All the notes are stored in a text file named `notes.txt`. Each note contains three details: a unique ID, a title, and its content. Whenever a new note is added, the program automatically generates an ID for it. The saved notes can also be accessed again after closing and restarting the program.

## Objective

The main objective of this project is to create a simple system for managing text notes. It also helps in understanding how different Python concepts can be used together to solve a practical problem.

## Working of the Project

When the program starts, it displays a menu with six options:

1. Add Note
2. View All Notes
3. Search Notes
4. Edit Note
5. Delete Note
6. Exit

The user can select any option by entering its number. The program performs the selected operation and returns to the main menu.

If the user enters an empty title while adding a note, the program displays an error message and does not save that note. Similarly, if an incorrect note ID is entered while editing or deleting, the program displays a message saying that the ID was not found.
